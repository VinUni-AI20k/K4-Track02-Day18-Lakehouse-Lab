# Khai báo sử dụng AI

OpenAI Codex được sử dụng để:

- thực thi tám notebook, đọc output và đối chiếu rubric;
- chạy test tái lập cuối cùng.

Các số liệu trong bài là output thực tế từ notebook; không thay bằng số minh họa
hoặc chỉnh sửa thủ công để báo PASS. Không dùng dữ liệu thật, API key hay model ngoài.
