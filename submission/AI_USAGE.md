# Phạm vi sử dụng AI

Công cụ hỗ trợ: ChatGPT/Codex trong workspace local.

Phạm vi hỗ trợ:

- Đọc README, hướng dẫn nộp bài, rubric, checkpoints và source notebook/script.
- Tạo môi trường Python 3.12, cài dependencies, chạy smoke test, pytest, `run_all.py`.
- Execute 8 notebook bằng nbconvert để lưu output thật vào `.ipynb`.
- Tạo file submission và tóm tắt bằng chứng từ output đã chạy.

Giới hạn:

- Không tạo số liệu giả.
- Không sửa assertion, không hạ ngưỡng rubric.
